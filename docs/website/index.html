RateLimiter-KMP

Kotlin Multiplatform rate limiting library. Semaphore, token bucket, adaptive, and throttling strategies for Android, Desktop, iOS, and Web.

RateLimiter

Semaphore-based concurrent operation limiting. Control how many operations run simultaneously.

TokenBucket

Token bucket algorithm allowing burst traffic while maintaining an average request rate.

AdaptiveRateLimiter

Self-adjusting concurrency limits based on success and failure feedback from your operations.

OperationThrottler

Per-operation-ID throttling within configurable time windows to prevent flooding.

Quick Start

val limiter = RateLimiter(maxConcurrent = 3)
val result = limiter.execute { fetchData() }
